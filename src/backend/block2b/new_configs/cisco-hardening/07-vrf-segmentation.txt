 VRF Segmentation Configuration in OSPF
 ================================
!
ip routing
!
! Define VRFs
!
vrf definition vrf-busn
!
vrf definition vrf-idmz
!
vrf definition vrf-proc
!
! Example SVI Assignments
!
interface Vlan10
 vrf forwarding vrf-busn
 ip address 10.10.10.1 255.255.255.0
!
interface Vlan20
 vrf forwarding vrf-idmz
 ip address 10.10.20.1 255.255.255.0
!
interface Vlan30
 vrf forwarding vrf-proc
 ip address 10.10.30.1 255.255.255.0
!
! Inter-VRF Routing Should Be Controlled via Firewall
!
router ospf 10 vrf vrf-busn
 router-id 1.1.1.1
 passive-interface default
 passive-interface Vlan10
 network 10.10.10.0 0.0.0.255 area 0
!
router ospf 20 vrf vrf-idmz
 router-id 2.2.2.2
 passive-interface default
 passive-interface Vlan35
 network 10.10.35.0 0.0.0.255 area 0
!
router ospf 30 vrf vrf-proc
 router-id 3.3.3.3
 passive-interface default
 passive-interface Vlan50
 network 10.10.50.0 0.0.0.255 area 0
